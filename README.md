# muse-hud-app

Built copy of Muse HUD, a MentraOS miniapp that shows Meta Muse replies on
Even Realities G1 glasses. This repo holds only the compiled app, served by
GitHub Pages so the Mentra app can load it from the phone.

## Install

In the Mentra app: **Settings → Miniapp Developer Settings → Load Miniapp
from URL**, then enter:

```
https://vicmarza.github.io/muse-hud-app/
```

## Updating

The files here are generated by `bun run site` in the source project. Replace
everything except this README with the new `site/` contents and push to
`main`; Pages redeploys on its own.
